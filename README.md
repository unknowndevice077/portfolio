# Portfolio

Next.js 16 + Tailwind v4 portfolio site.

## Deploy to Vercel

1. Push this repo to GitHub:
   ```bash
   git remote add origin <your-repo-url>
   git branch -M main
   git push -u origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new), import the GitHub repo.
3. No config needed — Vercel auto-detects Next.js. Click Deploy.
4. Optional: add a custom domain under Project → Settings → Domains.

## Local dev

```bash
npm install
npm run dev
```
